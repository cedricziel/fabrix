- Slice 11 needs the whole `add-inbox` stack merged and archived: it changes the "Open task" hook from inbox slice 2 (task 2.9), uses `people(companyID:)` from inbox slice 2, and its `inbox` spec delta applies only once `openspec/specs/inbox` exists.
- Shared files: only one open session at a time edits `FactoryService.swift`, `DemoFactoryService.swift`, `AppModel.swift`, `AppSection.swift`, `AttributeScrubber.swift`, `RootView.swift`, `SplitShell.swift`, `FabrixApp.swift` or a string catalog across both lanes. Phase 2 edits them only in the places design §14 names, which `add-inbox` doesn't touch. String catalog conflicts are resolved by re-running `scripts/sync-string-catalogs.sh`.

Every task runs `xcrun swift test --package-path Packages/FabrixKit`, `scripts/sync-string-catalogs.sh`, `scripts/check-feature-strings.sh`, `xcodegen generate` and both `xcodebuild` builds before it is ticked.
